# Documentation figures

The four mathematical figures are generated by [code/figures.py](../../code/figures.py).
Their explanatory captions and accessible image descriptions live beside them
in the Markdown documents. SVG text is stored as paths so formulas and fonts
remain consistent when GitHub displays the images.

| Figure | Used in | Source and scope |
| --- | --- | --- |
| `convergence-frontier.svg` | README | The five certified budget rows in REPORT §6; no interpolated frontier or unproved higher-degree optimum. |
| `terms-and-time.svg` | README | `results/benchmark_newton.json`; separate medians for setup, summation, and total time. Both panels use the same saved direct-summation benchmark. |
| `torus-and-lattice.svg` | EXPLORATIONS | Parametric torus paths with winding numbers (1,0), (0,1), and (2,3), together with their lifts in normalized lattice coordinates. |
| `symmetry-and-degree.svg` | REPORT | The exact level-2 involution and coefficient-field argument in REPORT §§3–4; the eight-to-four picture is schematic. |
| `museum-circle.png` | EXPLORATIONS | AI-generated conceptual artwork; it contains no measured data or mathematical claim. |

## Regenerate the mathematical figures

Use Python 3.11 or later. These dependencies are optional and separate from the
arithmetic verifier's requirements:

```sh
python -m pip install -r requirements-figures.txt
python code/figures.py
```

The default command writes PNG previews and SVGs to ignored
`results/latest/figures/`, leaving the checkout clean. It reads the current
report's table and the saved benchmark JSON directly, without rerunning the
benchmark or the optimality search. It fails if the expected five budget rows
are missing. The torus paths and symbolic pairing are drawn from the explicit
formulas in the script.

After reviewing a change, deliberately update the four committed SVGs with:

```sh
python code/figures.py --format svg --output-dir assets/figures
```

Refresh their hashes and any changed source/documentation hashes in
`MANIFEST.json`. The generator fixes SVG identifiers and omits timestamps to
make repeated rendering deterministic in the pinned environment. Other font or
rendering environments can still produce different bytes. The ordinary verifier
checks the committed asset hashes; it does not need the plotting dependencies.

## Museum illustration

`museum-circle.png` was generated on 8 October 2026 for this project using the
built-in image-generation tool. The original PNG is included unchanged. Its
prompt described a quiet ivory museum room, a wooden bench facing one framed
indigo circle, a copper-gold arc suggesting a traced circumference, soft side
lighting, and no people, text, equations, or logos. It supplies the exploratory
motivation and is not a diagram of the mathematics.
